# ShulBoard

פלטפורמה רב-קהילתית לצגי בתי כנסת. כל בית כנסת נרשם בעצמו, מקבל כתובת קבועה
לצג, ומנוהל מרחוק על ידי הגבאים — הכל בתוך המסלול החינמי של Cloudflare.

**חי:** https://shul-board.pages.dev

**הקוד פתוח וציבורי.** הריפו הזה הוא הקוד המלא של הפלטפורמה — שרת, ממשק הגבאים, הצג
והמתקין. אין בו סודות: סיסמת מנהל המערכת יושבת כסוד ב-Cloudflare Pages, הסיסמאות של
בתי הכנסת נשמרות במסד כגיבוב בלבד, ואין בריפו נתונים של אף בית כנסת. אפשר לקרוא, לדווח
על תקלות, להציע שיפורים, או להרים עותק משלכם על חשבון Cloudflare חינמי.

**רישיון:** [PolyForm Noncommercial 1.0.0](LICENSE.md). מותר להשתמש בקוד, לשנות אותו
ולהפיץ אותו **לשימוש לא-מסחרי בלבד** — בית כנסת, קהילה, עמותה, שימוש אישי. אסור למכור
אותו, לגבות כסף על שירות שמבוסס עליו, או לשלב אותו במוצר מסחרי. הרישיון מחייב את מי
שמקבל את הקוד, לא את בעל הזכויות: המחבר שומר לעצמו את הזכות להפעיל את השירות
ב-shul-board.pages.dev ולגבות עליו תשלום בעתיד.

מבוסס על [smart-zmanim](https://github.com/613avi/smart-zmanim) — אותו מנוע צג
(חישובי זמנים, פרשה, יארצייט), עם שכבת פלטפורמה חדשה במקום GitHub Pages + Actions.

## איך גבאי מקים צג

1. **הרשמה** בדף הבית — שם, כתובת באנגלית, שם הגבאי וסיסמה. דקה.
2. **אשף ההקמה** נפתח אוטומטית בכניסה הראשונה, חמישה שלבים שכל אחד נשמר לשרת:
   פרטים ומיקום (בחירת עיר בלחיצה או איתור כתובת) → זמני תפילה (שעות מופרדות בפסיק) →
   מראה ולוגו (מראה בסיסי, ערכת צבע, גופן, צבע הדגשה, העלאת לוגו ורקע — עם תצוגה מקדימה צמודה) →
   פריסת המסך (קלאסי או תבנית מסכים, יחס מסך) → הפעלה על המסך (קובץ התקנה, קישור, QR).
   אם המראה שנוצר ייחודי, השלב האחרון מציע לפרסם אותו לקהילה. אפשר לדלג, ואפשר להפעיל את האשף שוב מלוח הבית.
3. **מדריך צף** נפתח פעם אחת בכניסה הראשונה לניהול המלא (וזמין תמיד מכפתור "מדריך"):
   12 צעדים שמדליקים בזה אחר זה את הגלריה, הכוונון, הרקע והלוגו, תבניות המסך, העורך, המדיה, ההודעות, ההתקנה והשמירה.
4. **לוח הבית** של הניהול מציג את כתובת הצג, צ'ק-ליסט של מה הוגדר, ופעולות מהירות.

כמה גבאים? כמה שרוצים. סיסמה אחת לבית הכנסת, כל גבאי נכנס בשמו, ורואים ביומן מי שינה מה.

## מה הצג יודע להציג

מעבר לשלושת הלוחות הקלאסיים (זמני היום, זמני תפילות, לוח הנצחות), הצג מציע **קוביות**
(לשונית "מסכים ופריסה") ו**תכונות חכמות** ("מראה הצג" → "מה מוצג על הלוח"):

| | מה |
|---|---|
| שורת "היום" | חגים, ראש חודש, חנוכה (נר X), שבת מברכים + המולד, ערבי חג, צומות עם תחילה וסיום |
| התפילה הבאה | המניין הקרוב מודגש עם "בעוד X דק׳", תפילות שעברו מעומעמות או מוסתרות |
| הזכרות | יעלה ויבוא, על הניסים, ותן טל ומטר, "אין תחנון", "חצי הלל", "הלל שלם" לפי לוח השנה |
| זמנים | כל זמני היום לפי המיקום המדויק, כולל ר״ת וחצות הלילה; כל זמן ניתן להסתרה או לדריסה בשעה קבועה |
| קוביות | שעון גדול (דיגיטלי/אנלוגי), תאריך גדול, לוח שבת (הדלקת נרות, צאת השבת, ר״ת, פרשה, תפילות), היום, לימוד יומי, הקדשות וברכות (בסבב), שיעורים (היום ומחר), טקסט מתחלף, ספירת העומר, מזג אוויר, ספירה לאחור לתפילה, חלון מודעות |
| לימוד יומי | דף היומי, משנה יומית, רמב״ם, נ״ך, תהלים, ירושלמי ועוד |
| חלון מודעות | תמונות ו-PDF שהועלו מוצגים בסבב על הצג |
| מזג אוויר | טמפרטורה ותחזית ל-3 ימים לפי המיקום |
| מצב שינה | מסך שחור עם שעון קטן בין שעות שנבחרו |

**עיצוב**: 20 מראות מוכנים, 19 ערכות צבע, 7 סגנונות (כולל זכוכית ונועז), 9 גופנים,
6 פריסות, 13 תבניות מסך. לוגו, תמונת רקע, צבע הדגשה וגודל טקסט לכוונון עדין.

**מסכים מתחלפים**: במקום לוח אחד סטטי, בונים כמה מסכים שמתחלפים ביניהם — מתבנית מוכנה
או בגרירת קוביות על רשת. מתאים גם למסך אנכי.

**תבניות מהקהילה**: גבאי שבנה מראה משלו יכול לפרסם אותו, ובתי כנסת אחרים מעתיקים מראה
ופריסה בלחיצה — בלי לגעת בלוגו ובתוכן שלהם.

**מסכים בלייב**: לוח הבית של הניהול מראה כמה מסכים מקרינים את הצג כרגע, ואם כל אחד מהם
כבר מציג את השמירה האחרונה. כדי לתת למסך שם, מוסיפים לכתובת `?screen=שם`; המתקין עושה
זאת לבד עם שם המחשב.

**בתי כנסת קיימים לא מושפעים**: תכונות חדשות דולקות רק להרשמות חדשות. צג שכבר רץ
בבית כנסת ממשיך להיראות בדיוק כמו שהוגדר, גם כשהקוד מתעדכן.

## הפעלה על המסך

מלשונית "התקנה על המסך" מורידים קובץ התקנה מותאם לבית הכנסת (`ShulBoard-Setup-<slug>.exe`).
מריצים אותו על המחשב שמחובר למסך, והוא פותח את הצג במסך מלא ומגדיר הפעלה אוטומטית
בכל הדלקה. יש גם חלופה בלי התקנה — קובץ BAT שעושה את אותו הדבר — או פשוט לפתוח את
כתובת הצג בכל דפדפן וללחוץ F11. עובד גם על טלוויזיה חכמה וטאבלט.

## להרים עותק משלכם

הכל רץ במסלול החינמי של Cloudflare, בלי כרטיס אשראי: Pages + Functions, D1 (SQLite)
ו-KV. מדיה מוגבלת ל-5MB לקובץ ו-60MB לבית כנסת כדי להישאר בתוך המכסה.

```bash
npm install
wrangler d1 create shul-board                 # מסד הנתונים
wrangler kv namespace create SESSIONS         # סשנים
wrangler kv namespace create MEDIA            # קבצי מדיה
# מעדכנים את המזהים שהתקבלו ב-wrangler.toml
wrangler d1 execute shul-board --remote --file=schema.sql
wrangler pages secret put PLATFORM_PASSWORD --project-name shul-board   # סיסמת מנהל המערכת
wrangler pages deploy --project-name shul-board --branch main
```

הרצה מקומית:

```bash
wrangler d1 execute shul-board --local --file=schema.sql   # פעם אחת
wrangler pages dev --port 8790
```

פרטים טכניים — ארכיטקטורה, מיגרציות, API, בניית המתקין, חישוב המכסה — ב-[DEVELOPMENT.md](DEVELOPMENT.md).
